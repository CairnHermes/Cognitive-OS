# AI-Generated AGI Architecture Proposals — Research Packet

## What this is
A collection of AGI architecture proposals generated by AI systems using a
comparable prompt, preserved raw, and compared across a fixed set of
architecture dimensions. Purpose: make different architecture ideas comparable
and useful for Cognitive-OS planning.

## Collection method
- One comparable prompt (see `prompts.md`) sent to each AI system.
- Each raw output is saved separately in `raw_outputs/`, minimally cleaned
  (whitespace only, no rewriting).
- Attribution: model name, harness/tool, access date, and any human edits are
  recorded in `sources.md`.
- Outputs were generated on 2026-10-05.

## Honest systems-access disclosure
The posting requests ≥8 distinct AI systems and states: "If a model or tool
could not be accessed, state that explicitly instead of inventing output."
**This packet was produced on a machine with access to ONE model family
(Qwen 3.8-27B), reachable two distinct ways:**

1. **Qwen 3.8-27B (raw, via LM Studio local API)** — three independent
   samples at different temperatures (system_01/02/03).
2. **Hermes agent layer (Qwen 3.8-27B weights, multi-tool harness)** —
   the agent authored its own architecture proposal (system_04).

The systems NOT accessible on this box (and therefore NOT included, to avoid
fabrication): OpenAI/ChatGPT, Anthropic/Claude, Google/Gemini, xAI/Grok,
DeepSeek, Llama-based, Mistral-based, Perplexity. **A submission meeting the
"≥8 distinct systems" bar requires access to those systems** (an API key or a
web UI for each). This packet demonstrates the full method, comparison, and
synthesis pipeline on the 2 systems actually reachable, and is ready to be
extended to 8+ the moment those systems are reachable. No output for an
unaccessed system has been invented.

## Headline findings
- All three Qwen samples independently converged on a
  **separate procedural-memory layer** (skills / compiled tool sequences) as
  the load-bearing part of AGI — a strong signal that "learn by distilling
  successful procedures" is a robust proposal, not an artifact of one prompt.
- The agent-harness proposal (system_04) is the most concrete on
  **verification as a first-class phase** and on the **act-verify-distill-reuse
  loop** as the real source of general competence.
- The strongest original idea across all outputs: **reliable loop > bigger
  brain** — a small, verifiable, self-improving agent loop compounds toward
  general competence in a way that is auditable and human-supervisable, and
  that is distinct from the "train one giant model" path.

## Files
- `prompts.md` — exact prompt(s) used, per system.
- `raw_outputs/` — one file per system (4 files, 2 distinct systems).
- `comparison.csv` — structured comparison across the required dimensions.
- `summary.md` — synthesis of common patterns, disagreements, notable ideas.
- `synthesis.md` — a proposed combined architecture.
- `sources.md` — models, providers, dates, links, human edits.
